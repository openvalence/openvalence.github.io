Phosphor 0.1.641 pre-release

  • Windows

    Windows 10 and 11, 64-bit
    • InstallerPhosphor-0.1.641-windows-x64-setup.exe8.1 MB
    • Portable, no installPhosphor-0.1.641-windows-x64-portable.exe28.7 MB
    "Windows protected your PC"?

    Neither file is signed yet, so SmartScreen shows that warning: choose More info, then Run anyway. The portable exe needs the WebView2 runtime, which Windows 10 and 11 already include.

  • macOS

    Apple silicon. Intel Macs are not built.
    • Disk imagePhosphor-0.1.641-macos-arm64.dmg11.4 MB
    macOS won't open it?

    The app is not notarized: drag it to Applications, right-click it and choose Open. If macOS still refuses, use System Settings > Privacy & Security > Open Anyway.

  • Linux

    x86_64
    • AppImage, runs anywherePhosphor-0.1.641-linux-x86_64.AppImage86.3 MB
    • .deb, Debian and UbuntuPhosphor-0.1.641-linux-amd64.deb12.6 MB
    Running the AppImage

    The AppImage runs anywhere after chmod +x. The .deb is for Debian and Ubuntu.

  • Flatpak

    Linux, x86_64
    • Flatpak bundlePhosphor-0.1.641-linux-x86_64.flatpak8.2 MB
    Installing the bundle

    It needs the Flathub remote for the GNOME runtime, then flatpak install --user on the file.

Verify your download

Only download from github.com/openvalence. This site never hosts binaries. Compare your file against SHA256SUMS.txt with sha256sum -c SHA256SUMS.txt on Linux and macOS (shasum -a 256), or Get-FileHash in PowerShell.

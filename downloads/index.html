    Which one?

    MSIX: Windows verifies the signature and every file block before installing. Per-user, no admin, into the protected WindowsApps folder. Settings live in a per-app container that uninstall deletes.

    Installer: classic per-user setup, no admin. For machines where App Installer is removed or blocked by policy.

    Portable: extract the folder anywhere writable and run phosphor.exe. Data stays in PhosphorData beside it. Warns before writing from inside the zip, Downloads, Desktop, Documents or a drive root.

    All three need the WebView2 runtime, included in Windows 11 and current Windows 10. Windows 10 LTSC and IoT lack it and App Installer: use the installer, which downloads WebView2 during setup, or install the WebView2 Runtime (x64 offline installer) first.

Verify your download

Only download from github.com/openvalence. This site never hosts binaries. Compare your file against SHA256SUMS.txt with sha256sum -c SHA256SUMS.txt on Linux and macOS (shasum -a 256), or Get-FileHash in PowerShell.

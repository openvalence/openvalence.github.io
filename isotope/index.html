Isotope

Isotope is the planned firmware for Valence accessories: small ESP32 boards, such as a peristaltic pump or a motorized stand, that join a hub over ESP-NOW and show up in its catalog as ordinary channels.

Status WIP

WIP: a design home, nothing runs yet. The repo is public. It holds the design document and validation plans; there is no firmware, generator, flasher or builder. Nothing is built until the radio numbers it depends on are measured on dev boards. No license is chosen yet, so nothing in the repo is licensed for reuse.

The hub side is not built either. Nucleus runs Espressif's stock radio image today, which has no ESP-NOW, so the hub needs a change before any accessory can join.

How it will work

Hub and spoke
Accessories talk only to the hub. They never talk to a client or to each other. A client such as Phosphor sees accessory channels like any other channel in the hub's catalog. So no client needs accessory-specific code.
Join and declare
You open a pairing window on the hub. The accessory sends a join request, then declares its own channels. The hub stores them. So adding an accessory needs no change to the hub or the client.
The hub runs the logic
The relationships that drive an accessory live in the hub, not in the client. So an accessory behaves the same from any client.
Fails safe on its own
The hub sends a beacon once a second. With no beacon for 5 seconds, or on a goodbye or an e-stop, each actuator goes to the safe value it declared. So a lost hub leaves each actuator at a value you chose in advance.
Unencrypted
A deliberate choice, with obligations: the accessory clamps every actuating value, and the hub never treats accessory telemetry as safety-grade. So nothing safety-critical hangs on an accessory.
Small fleets
A hub addresses at most 19 accessories; 3 is typical. The limit comes from ESP-NOW's peer table.

Build order

Config and generator
A declarative config, shaped like ESPHome's, is the one place an accessory is described. The generator turns it into an image.
Web flasher
A browser page takes a config, makes the image and flashes it over Web Serial.
Visual builder
A blueprint-style editor on top of the config. It writes the same config and never does anything the config cannot.

How it fits

Isotope speaks Valence and takes every wire number from the spec. Anything it needs that the spec lacks goes through an RFC first. The hub is Nucleus. A plain on/off or PWM load, like a pump, does not need Isotope: the Flagship board has a pin for it. See the diagrams and Components for the whole system.

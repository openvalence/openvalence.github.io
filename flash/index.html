Web flasher WIP

Write firmware to an OpenValence board over USB from Chrome or Edge. The page takes release images from this site or .bin files from your computer, and sends them only to the board.

Work in progress. The offsets and image checks are tested against release images; the write itself has not yet run against a board from this page.

What you need

  • Chrome or Edge on a desktop computer. The page uses Web Serial; Firefox, Safari and phones have none.
  • A USB data cable to the board.
  • The images: a release hosted here, or your own build's files.

Device

The OSSM M5 Remote on a CoreS3 or CoreS3 SE. One full image at 0x0: bootloader, partition table and app. The image erases NVS (non-volatile storage, 0x9000 to 0xF000). The saved Wi-Fi and key map go with it. Pre-program Wi-Fi restores a network.

Nucleus on the OSSM Flagship, or nucleus-p4b on a barnacle's Stamp-P4. Bootloader at 0x2000, partition table at 0x8000, otadata at 0xF000, app at 0x20000 (slot ota_0). Each file is optional. The chip is never erased: NVS holds the hub identity, the trust ledger and pairing.

Flash with the motor powered down. On a barnacle, disconnect the wires to J8 first: the Stamp's USB-C feeds the R+D board's 5 V through it.

The barnacle's ESP32-WROOM-32D, through the R+D board's own USB-C (the CP2102 on UART0). One full image at 0x0. Erase is on, as in the release notes. Power off the board and disconnect the wires to J8.

Any ESP32 chip. Set an offset for each file. Once connected, the offset list holds the chip's bootloader offset and the board's partitions. Files named like bootloader.bin, partitions.bin, ota_data_initial.bin or firmware.bin get their offset filled in. Erase of the whole chip is never offered on an ESP32-P4.

Connect

Pick the board's port. The page resets the board into download mode, reads the chip, its MAC address and flash size, and the partition table at 0x8000.

Download mode by hand

Hold the CoreS3's reset button for about 3 s, until the small green LED lights. The screen stays dark. Then connect.

Hold the BOOT pad to GND while you plug in USB: TP903 on the Flagship, pad 36 (G35) on a bare Stamp-P4. Then connect.

No port listed: install the Silicon Labs CP210x driver. Port listed but no answer: set the baud to 115200 and connect again.

On most boards: hold BOOT (GPIO0), tap RESET, release BOOT, then connect.

Files

Each file is checked before the write: an image header (0xE9) where the bootloader or app starts, the chip the image was built for, an app where an app goes, the slot size and the flash size.

Pre-program Wi-Fi

Optional. Saves one network to the board's NVS (non-volatile storage) after the images, so it joins on first boot. The same SSID is replaced; a full list of four drops its last network. Every other NVS entry is kept.

Optional. Skips discovery; port 82 when left out.

The network goes only to the board: never stored by this page, never in the log (it records the NVS size and SSID length). The backup is the board's NVS as read, saved passwords included.

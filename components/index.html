The parts

A protocol, the firmware that speaks it, an app that drives it, a planner that turns it into motion, a board to run it on, and accessories, someday. Each one is its own repo. The system diagram shows how they connect.

Components

PartWhat it isStatus
Valence The protocol. The machine describes itself, apps draw it, the machine enforces its own limits. spec v1.0-draft
Nucleus Firmware for the OSSM Flagship board. Runs the Valence hub, the planner and the quadrature output on an ESP32-P4. works on the bench
Phosphor The app. A UI builder with plugins, a funscript player and a built-in Virtual machine. not released yet
Kinetic The motion planner. Timed knots in, jerk-limited motion out, same bits on every target. runs in Nucleus and in your browser
Hardware The OSSM Flagship board, in KiCad. in design
Isotope Firmware for small accessories that join the machine over ESP-NOW. WIP, design only
ButtplugIO A fork of buttplugio/buttplug carrying the Valence hardware manager, on branch valence. fork

Pawscript

A funscript editor with a semi-automatic scripter for animated clips.

Made for explicit content. For adults only (18+). GPL-3.0-or-later.

Get Pawscript Source

Status

Early access, for Windows.

The tracker usually gets the stroke direction backwards on the first try. You fix it once per scene with F or two anchors. Commit with Ctrl+S as you go, so you can step back.

Overview

Open a video and Pawscript finds the cuts. Paint the moving parts on one frame of a shot, press T, and a tracking model follows them through the shot. The tracked motion is your script at once, drawn on the stroke lane and written by the next publish. Flip the direction, set the depth with anchors, edit points by hand, check the script against your device, then publish a .funscript beside the video.

If you have used OpenFunscripter, the layout is familiar: video on top, lanes below, a playhead, number keys for points. Position 0 is fully in and 100 is out, on every lane, tracker and generator.

Features

Video and tracking

  • Scene detection finds hard cuts, fades to black, dissolves and still frames. You fix cuts with single keys.
  • TAPNext++ points and SAM 2.1 masks run on the graphics card. Optical flow and template match run on the CPU.
  • Painted parts carry over the cuts inside a scene, by name.
  • F flips a shot. Anchors at fully in and fully out set the depth. Shift+B bakes a shot so a re-track no longer moves it.
  • A shot tagger tags each scene, and a loop finder finds exact loops.
  • Videos: mp4, m4v, mkv, webm, mov and avi. A 480p proxy plays smoothly while the tracker reads the original.

Review

  • The problem finder checks the script against a device profile: speed limit, points too close, long gaps, jitter, points past the end of the video. F8 goes to the next problem and Ctrl+F8 applies its fix.
  • Statistics: strokes per minute, speed percentiles, the share of segments over the limit, per chapter.
  • Compare the script against a reference funscript or a tracker run, and adopt the parts you want.
  • The machine preview moves as the device will. With a planner profile, such as Nucleus, it shows where the planner will reshape a stroke.

Draft and Assist

  • Draft

    Ctrl+Shift+D runs scene detection, scene tags, a loop check, a first plan, a base track and Generate over the whole video. Each step is one undo entry.

  • Assist

    F6 asks the questions Draft cannot answer, one key each, such as which of two frames is deeper. The questions with the most effect on the script come first.

Editing

  • Points

    Place points with the NumPad (Blender keymap, the default) or the number row (OFS keymap). Every key can be rebound.

  • Transform tools

    Amplitude, time, density, speed, rhythm and variation tools, each with a preview before you apply it.

  • Fix a section

    Re-track, regenerate, flip, scale or retime one stretch. Points outside it stay where they are.

  • Axes

    Stroke plus roll, pitch, twist, surge, sway, vib and more, each on its own lane and written as its own funscript.

Generators and the node graph

  • Plan and Generate

    Lay out a scene as plan segments, each with a kind and a recipe. Ctrl+Shift+G writes the points. Where tracker runs exist, the follow recipes put the extremes on the tracked turning points.

  • Node graph

    Wire axes, tracker runs, the plan and the scenes through nodes. The document changes only when you bake, in one undo step. Presets cover tracker clean-up, roll from the stroke and more.

Saving and export

  • Continuous projects

    The project writes itself about a second after each change and survives the app being killed in the middle of a write. There is no Save for the project.

  • Commit and publish

    Ctrl+S commits a named point with an optional note. Ctrl+Alt+S publishes every axis as a funscript beside the video, numbered v1, v2 and on.

  • Other people's files

    The first overwrite of a funscript Pawscript did not write keeps the original as name.bak.

  • Export and packs

    Export all axes, one axis or a device-safe copy. Pack project writes one .pawpack with the video, the scripts and the project; every file's SHA-256 is checked when it opens.

  • Tabs

    Several projects open as tabs. A track keeps running in a tab you are not looking at.

Devices

  • Buttplug

    A Buttplug server inside the app plays the stroke axis on a toy over Bluetooth LE, serial or HID, in sync with the video.

  • Valence hub

    Works with Nucleus and Neutrino over WebSocket. Pawscript sends timed segments and the hub plans the motion within its own limits.

  • Stops

    Shift+Esc or Pause is the panic stop from anywhere. On a Valence hub it also pauses the hub. Pawscript never resumes motion by itself.

  • Network

    The app goes online only when you press Download for models or Check for updates. It sends no telemetry and has no account.

System requirements

  • Windows

    Windows 10 or 11, 64-bit. A portable folder: no installer, no admin rights. Windows 10 may need the WebView2 Runtime from Microsoft.

  • Disk and folder

    About 15 GB free. Keep the folder on a local drive with a short path, such as C:\Pawscript. The app refuses to start inside OneDrive, Dropbox, Google Drive or iCloud.

  • NVIDIA

    GTX 16xx or RTX 20xx and newer, RTX 50xx included, with driver 580 or newer. The runtime is PyTorch on CUDA 13.0. The default tracker settings use about 4 GB of video memory; the larger TAPNext++ model wants about 8 GB.

  • AMD

    A second runtime uses PyTorch on ROCm for Radeon RX 9000 and RX 7000 cards and the Radeon 780M and 760M, with Adrenalin 26.11.2 or newer. The app picks the runtime for your card.

  • Without a supported card

    The editor, playback and the CPU trackers work. TAPNext++, SAM 2.1 and the shot tagger need the card. GTX 9xx and GTX 10xx cards are not supported.

  • Other systems

    Linux and macOS are not built yet.

Download

Get Pawscript.zip from the latest release on GitHub. This site never hosts binaries. Extract it into a folder of its own and start Pawscript.exe. The first start asks which models you want, then downloads the runtime (2.3 GB) and those models.

The exe is not code-signed. If Windows SmartScreen stops it, click More info, then Run anyway.

Verify: the runtime and the tracking models download from dl.openvalence.org, and the app checks every file against the SHA-256 in the manifest built into it before it keeps the file.

Help > Check for updates installs an update only when its signature matches the key built into the app. In the app, F1 opens the quick start.

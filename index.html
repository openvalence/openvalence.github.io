OpenValence

Open hardware and software for linear motion machines. One hub holds the machine's state, any number of clients stay in sync with it, and every part of the stack is here in the open.

Docs GitHub

The parts

Valence

The protocol. Spec, registry, reference library, clients, tools, documentation.

Nucleus

Firmware for the OSSM Flagship PCB (ESP32-P4 + ESP32-C6). Pure ESP-IDF. Quadrature on the LP core, measured to within 8 ns.

Phosphor

The cross-platform client. Windows, macOS, Linux (Flatpak). Plugins, themes, a built-in simulator to try everything with no hardware.

Kinetic

The motion engine: trajectory planning, waveform shaping, blend and stretch policies. Header-only C++ on Ruckig, deterministic across targets.

Hardware

The OSSM Flagship PCB and everything physical around it. KiCad.

Isotope

Accessory firmware for the ESP-NOW network around Nucleus. WIP.

ButtplugIO

Fork of buttplugio/buttplug with the Valence hardware manager (branch valence).

Where things stand

The firmware homes a real rail, plays scripts, and talks to the client over Wi-Fi, with Bluetooth as the fallback. Phosphor builds for all three desktop platforms from one source. The protocol is pre-release: it changes through RFCs, and the registry is the single source of every wire number. Read the docs first if you want to build a client or a machine.

System overview

The firmware runs a hub that holds the machine's state. The desktop app, browser tabs, scripts and plugins connect to the hub as clients and stay in sync with it.

  1. Phosphoror any app

    Phosphor builds its pages from what the machine declares. Scripts, plugins and the page the machine serves connect the same way. Phosphor

  2. Valencethe protocol

    WebSocket over Wi-Fi, BLE for setup. The machine describes itself; apps send requests. Valence

  3. ESP32-C6radio

    Moves bytes over SDIO and runs Espressif's stock firmware, so the P4 is the only chip you flash. Chips

  4. HubNucleus on the ESP32-P4

    Holds the machine's state, clamps every request to the machine's limits and reports back what it actually did. Nucleus

  5. Kinetic²planner

    Turns timed knots into a 128 ms strip of positions on a 1 ms grid, so a short planner stall doesn't reach the motor. Kinetic

  6. LP corequadrature out

    Sends A/B quadrature from a 40 MHz crystal and parks itself if its 4 ms lease runs out. Motion

  7. Servo drivecloses the loop

    Follows the quadrature and closes the loop on the motor. Alarms come back to the P4, RS485 carries reads. Drive interface

  8. Motor and railwhere it ends up

    The firmware homes it and holds every move inside the rail window; the PCB's E-stop cuts motor power in hardware. Hardware

  9. Hover or tap a block for details.

How it's built

One person designs this and makes every decision; coding agents write most of the code under that direction.

Each repo holds its rules: a written doctrine, a registry that assigns every wire number, lint that fails the build, tests on every change, and a bench gate that requires firmware to move a real motor before a change is closed.

The Advanced pattern comes from fray-d's OSSM-Lite and keeps its CERN-OHL-S-2.0 license. The stroke patterns come from theelims' StrokeEngine. Type is Archivo and Martian Mono, both under the SIL Open Font License.

Try it without a machine

The planner runs in your browser today. The app runs its own virtual machine on your desktop. Neither needs a board.

Kinetic playground

The same Kinetic² planner that runs in the firmware, compiled to WebAssembly. Click the position trace to drop a knot, tune the planner options, and see what it did: the curve, its speed, acceleration and jerk against the ceilings, and every trim it had to make.

Kinetic gives the same bits on every target, and the firmware and the WebAssembly build use the same compiler rule for it. Same knots, same settings: the curve in your browser is the curve the machine plans.

Open the playground · Open the handles editor · About Kinetic

The handles editor loads a funscript as a chain of Bézier curves. Drag a knot's handles to set how fast it passes through. Bring your own .funscript or use the built-in one.

Phosphor and the Virtual machine

The Virtual is the machine's firmware compiled to WebAssembly, running inside Phosphor. It uses the same Valence protocol as a real machine, so everything you see in the clip is the real protocol, the real catalog and the real planner, minus the motor.

You get it with Phosphor: connect to "Virtual" in the machine list. Phosphor isn't released yet; see Downloads.
